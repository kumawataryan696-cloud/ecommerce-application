# E-commerce Application

This is a frontend e-commerce application built with React, TypeScript, and Vite.

---

## Tech Stack

* React
* TypeScript
* Vite
* Axios
* React Router DOM
* React Window
* Sass

---

## Getting Started

Install dependencies:

```bash
npm install
```

Run the app:

```bash
npm run dev
```

Build the app:

```bash
npm run build
```

Preview the build:

```bash
npm run preview
```
